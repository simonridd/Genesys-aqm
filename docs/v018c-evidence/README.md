# V0.18C evidence

All browser evaluation and API fixtures are fictional. New journeys abort external requests except their explicit fictional OAuth/API responses and reject unexpected writes. No paid Jev/provider call or production configuration write is made.

Reproduce from the dedicated worktree:

```sh
npm ci
npm test
npm run build
npm run typecheck:server
npm run build:server
npx playwright test tests/definition-authority.spec.ts
npx playwright test tests/authoring.spec.ts tests/policy-authoring.spec.ts tests/save-protection.spec.ts tests/form-composition.spec.ts tests/form-publication.spec.ts tests/control-plane-cache.spec.ts tests/operations.spec.ts
AQM_BROWSER_URL=http://127.0.0.1:4176/Genesys-aqm/ npx playwright test --config docs/v018c-evidence/playwright.config.ts
```

Local HTTP tests, Vite and Chromium require localhost socket access. The initial sandbox denied that access; successful recorded runs use the required execution permission. Server build/typecheck logs remain from this tranche because no backend source changes are needed.

Screenshots `forms`, `groups`, `routing`, `picker`, `routing-failure` and the corresponding viewport images are provided for 1440, 1920 and 390 widths. `exact-voice-routing.png` covers the actual voice-criteria regression. Full-page mobile authoring screenshots are intentionally long; viewport captures permit readable inspection.

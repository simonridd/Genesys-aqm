## Interpretation

Action counts are logical clicks/selections/text entries. Horizontal discovery and irrelevant vertical detours are recorded separately; ordinary scrolling through questions/evidence remains. Geometry measures presentation distance, not human task duration. The assessment uses the original five-point rubric and is scoped to the reviewer task. It is not a new whole-product review, independent-human study, physical-device qualification or accessibility certification.

## Reproduction

Run in the review worktree with installed locked dependencies and a compatible Playwright Chromium. No real credentials are required. Harnesses deny external/non-static traffic; do not remove those guards. `review.cjs` records findings and asserts calculator, navigation, review and storage invariants. `extra.cjs` performs keyboard/contrast/resize checks and a paced pitch (260s imposed dwell). `stable.cjs` takes settled first-screen images.

```sh
AQM_EVIDENCE_DIR="$PWD/docs/human-effectiveness-evidence" node docs/human-effectiveness-evidence/review.cjs
AQM_EVIDENCE_DIR="$PWD/docs/human-effectiveness-evidence" node docs/human-effectiveness-evidence/extra.cjs
AQM_EVIDENCE_DIR="$PWD/docs/human-effectiveness-evidence" node docs/human-effectiveness-evidence/stable.cjs
AQM_BROWSER_URL=https://simonridd.github.io/Genesys-aqm/ npx playwright test --config docs/human-effectiveness-evidence/regression.config.ts
```

Optional `PLAYWRIGHT_MODULE` points to a compatible installed module; `CHROMIUM_PATH` points to its installed executable. Defaults use the repository Playwright package and its normal browser. Regression fixtures simulate an authenticated session entirely through route fulfilment. Do not interpret them as live authentication or provider proof.

Existing showcase tests also write their pre-existing `docs/ipi-evidence` outputs. Revert only those generated outputs if a rerun changes them; keep this review branch restricted to review files. The original run introduced no tracked changes there.

Build/unit/browser logs: [build](build.txt), [units](unit-tests.txt), [browser regressions](browser-regressions.txt).

# V0.4 monitoring architecture

`planPolicyRun` in `src/domain/policyRuns.ts` is a pure function over a policy, bounded candidate population, form definitions, prior records, source, and resolved period. It never calls Jev or writes browser storage. The UI resolves the manual period, reads the source's complete bounded candidate list, then loads only sampled conversations for transcript availability. `executePolicyRun` receives the frozen plan through the preview, creates a PolicyRun snapshot, and runs pending conversation/form assignments with concurrency two. A future server scheduler should resolve a period, obtain source candidates, call the same planner, and execute only after its own authorization and budgeting controls.

Sampling uses unsigned FNV-1a 32-bit hashing with `Math.imul`, sorted ascending with conversation ID as a tie breaker. The hash input contains the policy ID, concrete period start and end, strategy, percentage/count, optional explicit seed, and conversation ID. Percentage rounds down. Candidate order has no effect. `all` is ID ordered. The algorithm is designed for explainable reproducibility, not cryptographic randomness or per-agent balancing.

Duplicate checks use only successful saved Jev records matching source, conversation ID, form ID, and form version. Failed attempts are eligible for retry. A partial prior form set generates only the missing assignments. An explicit re-evaluation override adds completed assignments back to the request count. Transcript-unavailable sampled interactions remain in the sample and reduce transcript availability and sample completion; they are never sent to Jev.

Run snapshots contain IDs and derived metadata, not raw messages. They are local to the browser and do not synchronize across devices. Browser-local history limits enterprise-wide duplicate prevention until a server-side record store is added. Genesys source, PKCE, and media retrieval remain in their existing modules. Real and synthetic runs are filtered separately in Analytics; the operational default is real only.
